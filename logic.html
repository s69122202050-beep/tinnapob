SET LOGIC

🧠 ระบบ Set Logic

เรียนรู้การทำงานของ Set และ Logic ผ่านตัวอย่างการเลือกซื้อทุเรียน

📚 Set Logic คืออะไร?

Set Logic คือการนำข้อมูลที่อยู่ในรูปแบบเซต มาวิเคราะห์ความสัมพันธ์และเงื่อนไข เพื่อช่วยให้ระบบสามารถตัดสินใจได้ว่า สินค้าใดตรงกับความต้องการของลูกค้า

🟢 Set A

กลุ่มทุเรียนที่มีรสชาติหวาน

หมอนทอง ก้านยาว ชะนี

🟡 Set B

กลุ่มทุเรียนที่มีราคาต่ำกว่า 200 บาท

หมอนทอง ชะนี

⚙️ Function ของ Set Logic

ตัวดำเนินการที่ใช้ในการประมวลผลข้อมูล

AND

AND — และ

ต้องเป็นจริงทั้งสองเงื่อนไข จึงจะได้ผลลัพธ์เป็นจริง

Set A AND Set B
= สินค้าที่อยู่ทั้ง A และ B
= หมอนทอง, ชะนี
OR

OR — หรือ

ถ้าเงื่อนไขใดเงื่อนไขหนึ่งเป็นจริง ก็สามารถเลือกข้อมูลได้

Set A OR Set B
= สินค้าที่อยู่ใน A หรือ B
NOT

NOT — ไม่

ใช้สำหรับกลับค่าของเงื่อนไข หรือเลือกข้อมูลที่ไม่อยู่ในเซต

NOT Set B
= สินค้าที่ไม่อยู่ใน Set B
IF / ELSE

IF / ELSE — ถ้า / มิฉะนั้น

ใช้ตรวจสอบเงื่อนไข แล้วเลือกว่าจะทำอะไรต่อ

IF ราคา < 200
→ แสดง "ราคาประหยัด"
ELSE
→ แสดง "สินค้าพรีเมียม"

🔧 Function ที่ใช้ในระบบ

ตัวอย่างการนำ Set Logic ไปใช้กับระบบร้านทุเรียน

filterProducts()
กรองสินค้าตามประเภททุเรียน
addToCart()
เพิ่มสินค้าลงตะกร้า
checkout()
ตรวจสอบและสั่งซื้อสินค้า
IF / ELSE
ตรวจสอบราคาและส่วนลด
